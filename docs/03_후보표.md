# 3단계 · 후보 선정과 걸러내기

작성일: 2026-11-17
확인 방법: 라이선스는 Hugging Face 모델 API의 공식 카드 값(cardData.license)과 로컬에 설치한 패키지의 배포 정보(importlib.metadata)로 확인했다. 웹 검색 결과나 미러 저장소의 표기는 근거로 쓰지 않았다.
**가격, 라이선스, 지원 언어는 바뀐다. 아래 날짜(2026-11-17) 기준이다.**

### 걸러낸 후보가 점수로는 어땠을까 (회고 3번용)
- 이번 PoC에서는 탈락 후보를 **돌리지 않았다.** 그래서 점수 순위가 없다. 한국어 특화인 VARCO는 성능이 좋을 수 있지만 비상업 조건 때문에 사내 업무에 쓸 수 없다. 걸러낸 것이 이 판단이다.
- 라이선스로 걸러낸 모델이 사실은 가장 정확할 수 있다는 점을 결론에 남긴다.

## 2. 남은 후보 3개와 성격 비교
크기가 아니라 성격이 다른 후보로 골랐다.

| 항목 | A. PP-OCRv5 한국어 + 규칙 파싱 | B. PaddleOCR-VL 0.9B | C. Qwen3-VL-2B-Instruct |
|---|---|---|---|
| 만들어진 목적 | 글자 인식 전용 | 문서 파싱 전용(표·레이아웃) | 범용 |
| 실행 위치 | 노트북 | 노트북 | 노트북 |
| 결과의 형태 | 글자 + 박스 좌표 + **신뢰도** | 구조화된 표/마크다운(위치와 신뢰도 제공 여부는 실측으로 확인) | JSON 출력(프롬프트로 지정), 위치·신뢰도 없음 |
| 기대되는 강점 | 속도, 박스와 신뢰도가 있어 기준 3·5에 유리 | 표 구조를 한 번에 복원 | 손글씨 정정·줄바꿈 같은 문맥 판단 |
| 기대되는 약점 | 표를 직접 조립해야 함(규칙 코드), 손글씨 정정 해석 불가 | 신뢰도 없으면 "확인 필요" 판정 어려움 | 숫자 환각 위험, 근거 위치가 없어 기준 5 어려움 |
| 한국어 근거 | 한국어 전용 인식 모델 있음 | 공식 문서의 언어 지원은 확인 못 함 → **한국어 실측 필수** | 확인 못 함 → **실측 필수** |

기준 3(확인 필요 판정)과 5(위치 추적)를 어떻게 만들지는 후보마다 다르다. B와 C에서 신뢰도나 위치가 안 나오면, 같은 모델을 두 번 돌려 결과가 다른 값을 "확인 필요"로 보는 방식 등을 5단계에서 정한다.

## 3. 환경 확인 (2026-11-17)
- 노트북: RTX 4050 Laptop VRAM 6GB, RAM 약 15.7GB, 디스크 여유 약 107GB
- 설치됨: paddleocr 3.7.0, paddlepaddle 3.3.1, paddlex 3.7.2, opencv, pymupdf 2.1
- **없음**: torch, transformers
- **paddlepaddle 3.3.1은 CPU 빌드다**(2026-11-17 `paddle.device.is_compiled_with_cuda()` = False). GPU(VRAM 6GB)는 후보 A·B 모두 쓰지 못했고, 둘 다 CPU에서 돌렸다. 처음 계획의 "VRAM 6GB 안에서 돎" 조건은 이 PoC에서는 측정할 대상이 없었다.
- 추가 설치(2026-11-17 사용자 허용): 후보 B용 `paddlex[ocr]` 추가 패키지 11개와 보조 패키지 10개. 기존 패키지 버전은 바뀌지 않았다.

## 4. 라이선스 주의 (제품에 넣어 배포할 때)
- **PyMuPDF 2.1은 AGPL 또는 상용 라이선스**다. PoC에서 PDF를 이미지로 바꾸는 데 쓰는 것은 문제없지만, 닫힌 제품에 넣어 배포하면 소스 공개 의무가 걸린다. 배포 계획이 생기면 상용 라이선스를 살지 다른 PDF 렌더러로 바꿀지 정해야 한다. 이미 설치돼 있는 `pypdfium2`(5.15.2)가 대체 후보다. 배포 정보의 라이선스는 이 PoC에서 확인하지 않았으니 교체 전에 확인한다.
- paddleocr 패키지 안에 클라우드 API 클라이언트(`_api_client`)가 있다. 실행 스크립트는 파이썬 소켓의 외부 연결을 막고 돌렸고, 두 후보 모두 차단 기록이 비어 있었다(`params.json`의 `network_attempts_blocked`). **파이썬 밖(C++)에서 나가는 연결은 이 방법으로 확인하지 못한다.**

## 5. 판정과 실행 결과 (2026-11-17~18)
- 5단계에서 실제로 돌린 후보: **A, B**. 후보 C는 **시도하지 않음**(아래).
- **후보 C 제외 사유**: 사용자가 torch·transformers 설치와 Qwen3-VL-2B 가중치(약 4.3GB) 다운로드를 허락하지 않았다. 공식 카드의 라이선스(Apache-2.0)와 가중치 크기는 확인했지만 VRAM 6GB에서 실제로 도는지, 한국어를 읽는지는 **측정하지 못했다.** 범용 모델이 이 업무에서 어떤지는 이 PoC로는 답할 수 없다.
- 후보 비교는 두 후보뿐이라 "성격이 서로 다른 후보 3개"라는 설계 원칙은 일부만 지켰다. 두 후보 모두 Paddle 계열이라 범용 모델과의 비교가 빠져 있다.
- 실측 결과는 `docs/05_결과비교.md`.
